# Copilot Project Instructions

## Code Style
- Write clean and readable Python code.
- Follow PEP 8 standards.
- Use meaningful variable and function names.
- Avoid duplicate code.
- Add comments for important logic.

## Project Structure
- Keep Flask routes and Sudoku logic separated.
- Create reusable functions.
- Handle errors properly.

## Sudoku Features
- Support Easy, Medium, and Hard difficulty levels.
- Generate puzzles with one unique solution.
- Lock pre-filled cells.
- Validate user moves.
- Provide hints and completion messages.

## UI Requirements
- Responsive design for mobile and desktop.
- Support dark mode.
- Keep UI simple and accessible.

## Development Approach
- Test changes before moving forward.
- Review AI-generated code before accepting.
- Prefer maintainable solutions over quick fixes.
